# 两阶段视频复刻配置实施计划

## 已确认产品判断

- 第一步只建立任务：上传参考视频、选择复刻目的，并可提前选择投放国家。
- AI 先分析参考视频，再根据识别到的商品露出、人物、场景、字幕和口播生成第二阶段配置。
- 同商品跨国家本地化不强制上传“目标商品”；优先沿用参考视频商品，仅在画面清晰度或资料不足时提出补充建议。
- 替换新商品时，第二阶段才要求从产品库选择或上传目标商品资料。
- 第二阶段确认后才创建候选视频槽位并进入生产。

## 实施步骤

1. 通过模型测试锁定 intake → analyzing → plan → running 的阶段转换。
2. 在模型中增加参考视频分析结果、动态配置段落和按复刻目的变化的校验。
3. 将会话内长表单拆成“建立复刻任务”和“确认生产方案”两张 B 端结构化工具卡。
4. 保留候选视频管理、卡片/表格切换和最右视频详情交互。
5. 浏览器验证两条路径：同商品跨市场、替换新商品。
6. 同步 current 产品/设计文档、变更包和变更记录，通过文档治理检查后提交并部署。
