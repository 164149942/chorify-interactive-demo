# Chorify Chat 内视频复刻工具交互设计

日期：2026-08-11  
状态：已确认，已实现并验收

## 1. 目标

在 Chorify 现有 AI Chat 页面内增加“视频复刻”专业工具。用户不需要进入独立营销工厂页面，而是在当前会话中调出结构化表单、确认复刻条件，并使用现有任务侧栏和视频预览侧栏管理生成结果。

本轮交付为独立纯前端交互 Demo，不修改公司线上代码，不连接真实 AI、产品库、上传、视频生成、积分扣费或后端任务。

## 2. 产品对象与边界

- AI Chat 是统一交互入口，不是新的业务对象。
- 视频复刻表单是 AI 可以在对话中调用的专业工具组件。
- 用户确认表单后创建一张复刻生产订单。
- 一条 AI 会话最多绑定一张视频复刻生产订单。
- 订单边界为：`1 个参考营销视频 × 1 个目标商品 × 1 个目标市场 × N 条候选视频`。
- 再次发起新的复刻任务时新建会话，可继承必要的结构化商品或市场信息，但不在同一会话并列管理多张订单。

## 3. 页面骨架

Demo 参考现有 Chorify Chat 页面，保持四个区域：

| 区域 | 职责 |
| --- | --- |
| 左侧会话栏 | AI Chat 模块、工具入口、历史会话和账户 |
| 中央对话区 | 自然语言沟通、视频复刻表单、订单摘要和过程消息 |
| 右二任务栏 | 当前复刻订单、全部候选视频及其状态 |
| 最右预览栏 | 当前选中候选视频的预览、版本、审核和修改入口 |

顶部现有“任务面板”和“预览面板”按钮继续控制右侧两栏。页面不新增营销工厂一级导航，也不跳转到另一套工作台。

## 4. 视频复刻入口

三种入口调用同一个表单状态：

1. 新会话首页的“视频复刻”能力卡。
2. 对话输入框附近的“视频复刻”工具按钮。
3. 用户输入类似“帮我复刻这个视频，把产品换成我的商品”的自然语言后，由 AI 推荐并调出表单。

重复触发时不得插入多张互不关联的表单：

- 尚未创建订单：定位并展开当前表单。
- 已创建订单：定位订单摘要，并提供“重新打开配置”。
- 当前会话已绑定订单且用户要做新的核心任务：提示新建会话。

## 5. 对话内结构化表单

表单不是独立页面，也不是替换整个中央区域的宽屏工作台。它以一条 **AI 工具消息**嵌入现有 Chat 对话流：左侧保留 AI 头像，右侧工具卡使用该消息在原对话内容轨道内的可用宽度。

- 普通消息、工具表单和底部输入框共享同一条最大 `920px` 的 Chat 内容轨道。
- 工具表单可以比普通文本气泡更宽，但不得改变 Chat 主栏宽度，也不得把输入框拉宽。
- 表单打开或重新编辑时，任务面板和预览面板不因表单本身而自动出现。
- 表单较长时随对话内容区上下滚动，底部输入框保持在原位置。
- 提交后才打开任务面板；选中可预览候选后才打开最右预览面板。

### 5.1 基础字段

表单首屏包含：

1. 参考爆款视频：上传或使用演示素材占位。
2. 目标商品：从产品库选择或直接上传商品图片和资料。
3. 投放国家：单选下拉。
4. 本地化：国家联动推荐语言、字幕、画面文字和口播；允许用户覆盖语言。
5. 候选数量：`1 / 3 / 5`。

商品替换为必选规则：参考视频中所有商品出现位置都替换为目标商品，不作为可取消的变化项。

### 5.2 可选变化目标

用户多选“本次还想改变什么”，表单只展开已选择项目：

- 人物：从人物库选择、上传人物照片或让 AI 按国家与描述生成。
- 场景：选择参考视频中的指定镜头环境并替换。
- 视频片段：上传或引用一段视频，替换参考视频中的指定时间段。
- 品牌 Logo：上传或从品牌资产中选择。

未选择的对象默认继承参考视频。镜头增删、排序和自由工作流不进入本轮 Demo。

### 5.3 低频设置

比例、分辨率、平台和其他生成参数进入“更多设置”折叠区，避免首屏过重。

### 5.4 表单状态

- 初始态：可编辑，显示缺失字段提示。
- 编辑态：字段联动，可通过自然语言模拟修改。
- 校验失败：定位缺失或冲突字段，不创建订单。
- 已确认：折叠为订单摘要卡。
- 重新编辑：在原消息位置恢复已填写表单。

## 6. 自然语言与表单双向联动

Demo 至少模拟以下指令：

- “改成投放巴西。”：国家切换为巴西并联动葡萄牙语与字幕。
- “生成 5 条。”：候选数量切换为 5。
- “人物换成拉丁裔年轻女性。”：选中人物替换并写入描述。
- “其他都保持原视频。”：关闭场景、片段和 Logo 等非必要替换项。

每次模拟更新后，AI 回复简短变更摘要，并允许用户重新打开表单核对。

## 7. 确认生产后的联动

用户点击“确认配置并开始复刻”后：

1. 当前会话绑定一张生产订单。
2. 表单折叠为订单摘要，显示参考视频、商品、国家、候选数量和变化项。
3. 右二视频管理栏自动打开。
4. 右二立即显示全部 N 条候选槽位，不等待第一条视频完成；不在列表上方重复放置批次进度概览。
5. 候选槽位模拟不同状态：待生成、生成中、可预览、缺少资料或失败。
6. 技术执行记录不作为第一层列表，折叠在对应候选视频下面。
7. 最右详情栏保持关闭，直到用户明确选择候选视频。

## 8. 右二视频管理

右二首屏直接承担候选视频管理，不在顶部重复放置大块批次进度概览。标题显示“视频管理”和候选数量，并提供卡片/表格两种视图：卡片视图突出封面与当前状态，表格视图按视频、状态、版本和时长快速扫描；视图偏好保留在当前订单内。

每条候选至少显示：

- 编号与标题。
- 缩略图或状态占位。
- 当前状态。
- 版本号。
- 时长与比例。
- 当前主要动作。
- 可展开的执行记录。

用户点击任意候选后保持列表选择态，并打开最右详情栏。可预览候选显示视频查看与审核；等待、生成中或缺少资料的候选显示对应生产状态。切换候选直接更新详情，不回到对话流寻找历史结果。

## 9. 最右视频详情

当前 Demo 使用视频或视觉占位，不执行真实生成。预览栏包含：

- 视频画面占位与播放控制外观。
- 候选编号、状态和版本。
- 复刻要求摘要。
- “要求修改”“重新生成”“下载成品”占位动作。
- 修改要求输入框，发送后作为消息进入中央当前会话。

未完成候选不伪造播放器，只说明当前状态与下一步；未人工通过的候选不进入真实导出。本轮按钮只演示状态反馈，不产生外部副作用。

## 10. 重新打开配置

订单摘要持续提供“重新打开配置”：

- 在原消息位置恢复已填写内容。
- 打开或取消修改不清除候选、选中视频、版本和预览状态。
- 保存后模拟重新建立 N 个候选槽位，并提示旧结果已保留为上一轮。
- 若修改参考视频、目标商品或目标市场，正式产品应复制配置并新建会话；Demo 使用说明性提示表达该边界。

## 11. Demo 演示主线

第一版必须跑通：

```text
新会话
→ 点击“视频复刻”
→ 对话中出现结构化表单
→ 填写参考视频、商品、国家和候选数
→ 选择人物/场景等变化项
→ 确认生产
→ 右二出现全部候选槽位
→ 点击候选打开最右预览
→ 从预览发出修改要求
→ 中央对话收到修改消息
→ 重新打开配置并保持结果状态
```

## 12. 视觉与实现约束

- 尽量还原现有 Chorify Chat 的浅色界面、紫色品牌色、细边界、圆角卡片和紧凑侧栏。
- 欢迎态与工具打开后的对话态共用同一套页面背景和主输入框视觉；调用工具不得改变底色、渐变、输入框白底、边框、圆角、阴影或尺寸。
- 点击工具只新增对话消息与结构化表单；当前任务信息不在输入框中重复展示。
- Demo 独立实现，不抓取或复制公司线上源代码。
- 主要验收尺寸为 1920×1080 与 1366×768。
- 各栏独立滚动，中央输入框和右侧主要操作保持可达。
- 使用现有 Git 仓库新分支保存，不复制破坏旧 Demo。

## 13. 验收标准

- 三种入口能够打开同一张视频复刻表单。
- 表单条件展示、国家联动、候选数量和校验可交互。
- 自然语言模拟指令可以修改同一份表单状态。
- 一条会话不能创建两张复刻订单。
- 确认后右二立即显示正确数量的候选槽位。
- 执行记录位于候选内部，而不是与候选并列。
- 点击候选打开最右预览并保持选择态。
- 从预览提交修改要求后，中央对话出现对应消息。
- 重新打开或取消配置不会清空候选与预览。
- 页面在两个目标尺寸下无页面级溢出，主要动作可达。
- 表单位于 AI 工具消息内，表单、对话消息和输入框保持同一 Chat 内容轨道；打开表单不会改变对话宽度。
- 工具调用前后画布背景和输入框计算样式一致。
- 提交前任务面板和预览面板均关闭；提交后任务面板打开，重新打开配置仍回到原对话位置并保留已填写值。
